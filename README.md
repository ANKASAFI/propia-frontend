# PROPIA

Aplicación web de PROPIA. El diseño sigue el canvas de `docs/design/propia-canvas.html`: mismos colores, logo, iconos y composición.

La API tiene que estar corriendo en el puerto 3000. Esta app usa el 3001 y le reenvía `/api`.

```bash
pnpm install
pnpm dev
```

Abre `http://localhost:3001`.
